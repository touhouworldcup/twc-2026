# twc-2026

*This is a bundle for [NodeCG](https://nodecg.dev/); if you do not understand what that is, we advise you read their website first for more information.*

twc-2026 is a bundle for the [NodeCG](https://nodecg.dev/) broadcast graphics framework/application producing the [Touhou World Cup 2026](https://touhouworldcup.com) stream layouts. Internally, it leverages [nodecg-speedcontrol](https://github.com/speedcontrol/nodecg-speedcontrol) for match management.
